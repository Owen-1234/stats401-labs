Method note

From table to visual evidence.

The source data are loaded from students.csv. During row conversion, every score is converted from text to a number. D3 then binds one record to one SVG rectangle, so the graphic remains directly connected to the dataset rather than being drawn manually.

Source: Course-provided illustrative student score dataset. Scores range from 0 to 100.
