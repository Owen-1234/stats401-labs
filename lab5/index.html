Design rationale

Node-link design

Categorical color identifies district, while proportional symbol area represents passenger volume. Shape separates station functions without competing with color. Route hue distinguishes service and line width makes long trips salient. Dragging resolves overlap. Highlighting and tooltips preserve station-level inspection within the dense display.

Figure 2 · Adjacency matrix

Rows and columns represent the same stations. Filled cells indicate direct routes. Color identifies route type and opacity represents travel time. Labels are grouped by district, then station type.

Figure 2. The symmetric pattern reflects an undirected network. Empty rows and columns identify isolates. Darker cells represent longer direct travel times, and the colored side bands show district membership.

Design rationale

Matrix design

Filled cells preserve route existence, type, and travel time. Symmetry reflects undirected travel. Sorting by district creates blocks for comparing within- and between-district connections. Station type supplies a secondary order, and colored labels retain district identity. Passenger volume remains in tooltips because another matrix channel would reduce legibility.

Data and interpretation

A synthetic network for visualization practice

The two external CSV files contain 50 stations and 50 direct routes. D3 data binding constructs both views from the same records. Because the dataset is synthetic and the force layout does not use geographic coordinates, the figures support structural comparison rather than claims about a real transit system.
