Lab 5 · Interactive Network Visualization

Urban Transit Network

A node-link diagram and an adjacency matrix represent the same transit network. Together, the views support analysis of station connectivity, district structure, passenger volume, travel time, and route type.

Dataset

50 stations and 50 direct routes

The course-provided files describe a synthetic, undirected transit network across five districts. Station records contain district, daily passenger volume, and station type. Route records contain travel time and service type. Because the data contain no geographic coordinates, both views represent network structure rather than physical location.

Design rationale

Node-link design

District uses categorical color, passenger volume controls symbol area, and station type uses shape. Route hue distinguishes Metro, Express, and Shuttle. Width increases with travel time so long direct trips remain visible. Dragging reduces overlap. Highlighting isolates a station’s immediate neighborhood, and tooltips report exact attributes.

Figure 2 · Adjacency matrix

District ordering reveals the network’s block structure

Rows and columns represent the same stations. Filled cells indicate direct routes. Color identifies route type and opacity represents travel time. Labels are grouped by district, then station type.

Figure 2. The symmetric pattern reflects an undirected network. Empty rows and columns identify isolates. Darker cells represent longer direct travel times, and the colored side bands show district membership.

Design rationale

Matrix design

Rows and columns follow the same station order. A filled cell denotes a direct route, hue shows route type, and opacity increases with travel time. Ordering by district and then station type creates comparison blocks. District-colored labels preserve membership. Passenger volume remains in label tooltips because another cell encoding would reduce legibility.
