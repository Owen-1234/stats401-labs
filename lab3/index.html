Dataset description

Debt to the Penny, acquired programmatically

Each row is one reporting date from the U.S. Treasury’s official Debt to the Penny dataset. A Python script queried the REST API as JSON, followed all pages automatically, paused one second between requests, validated the returned records, and saved the result as CSV. Dollar values are nominal and reported by the source.

Reproducible and responsible collection

The script requests 100 records per page from January 1, 2015 onward. It uses an informative user agent, a 30-second timeout, automatic retry with exponential backoff, HTTP status validation, JSON structure checks, and a one-second delay between pages. The final record count is compared with the API’s reported total before the CSV is written.

Dates are unique identifiers. Currency fields are converted to numeric values, and two derived attributes support analysis: daily change in total debt and the public share of total debt. The first daily-change value is intentionally blank because no earlier observation is included for comparison.

Data quality note: On August 4, 2025, the two component values exceed the reported total by $10 billion. The script does not silently alter an official value; it records the difference in component_difference_usd. Source: U.S. Treasury Fiscal Data.
