Design description

Rectangle area encodes GDP because area supports part-to-whole comparison within a fixed frame. Color encodes GDP status as a categorical attribute. Green indicates increase, amber indicates no change, and red indicates decrease. Both figures use identical data, dimensions, country ordering, and colors, which isolates segmentation strategy as the only design difference. Nested borders and labels identify continents, areas, and countries. Tooltips supplement the visible labels with the complete hierarchy path, exact GDP, and status. The squarified layout produces compact rectangles with relatively balanced aspect ratios. These shapes improve label fit and facilitate comparison among countries with similar GDP values. The slice-and-dice layout alternates horizontal and vertical partitioning across hierarchy levels. Its bands make the nested structure easier to trace, although countries with small GDP values form narrow cells. Comparing the two figures demonstrates that tiling changes spatial organization and readability while preserving the underlying hierarchy and quantitative relationships.
