Design reflection · 100–200 words

Why this interaction fits

I extended my Lab 8 semantic map of the DKU Undergraduate Bulletin. Speech recognition now places interim and final words in an editable command field. Readers review the text and press Search / apply before the map changes. The same field accepts typed commands, while the original search box, menus, and mouse controls remain available. This interaction helps readers change their question while looking at the map without requiring immediate recognition accuracy. “Find credit” highlights matching passages and opens a short, page-ordered list so readers can move from a pattern to source text. “Show policy” isolates a modeled topic. The interface reports the words heard and the action taken. Microphone access starts only after the reader presses Start voice control. Listening ends after one command and can be stopped sooner. Browser speech recognition can be unavailable or mishear specialized Bulletin terms. Reviewing the transcript and using conventional controls provide a fallback when recognition fails. The result list shows the first five matching passages; the map retains all matches.
