# STATS 401 Lab Portfolio

Course website for **STATS 401: Data Acquisition and Visualization**.

## Lab 1

Lab 1 loads the course-provided `data/students.csv` file with D3 v7, converts scores to numbers during CSV row parsing, and creates a responsive SVG bar chart through D3 data binding.

## Run locally

From the project directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in a browser.
